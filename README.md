# 쿼터 라인업 메이커

아마추어 축구 4쿼터 경기에서 **출전시간 공정 배분 + 포지션 적합도 최대화**를 동시에 만족하는 쿼터별 라인업을 자동으로 짜주는 웹앱.

- 선수별 포지션 숙련도(3=주, 2=서브, 1=커버) 입력
- 출석 체크 + 쿼터별 가용 여부(지각/조퇴)
- 포메이션 자유 설정 (기본 4-2-3-1)
- 브라우저 안에서 HiGHS(MILP 솔버, WebAssembly)로 최적해 계산 — 서버 없음, 데이터는 localStorage에만 저장
- 결과: 쿼터별 피치 배치, 벤치, 출전표, 카톡용 텍스트 복사

로컬 실행: `python3 -m http.server` 후 http://localhost:8000
